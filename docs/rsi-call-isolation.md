# RSI 单调用故障隔离

本机制属于通用 RSI，不包含数据集专用分支。

| 环节 | 故障处理 | 保留内容 |
| --- | --- | --- |
| 单题执行 | 仅在宿主明确授权的隔离环境中重建失败题的会话 | 其他题和已完成试次 |
| 自定义评分器 | 对同一执行证据重试评分 | 对话和工具执行结果 |
| 执行诊断 | 只重试诊断；文件格式不合格时带校验原因修复 | 官方分数，包括 0 分 |
| 调优文件编辑 | 重试前恢复该次编辑前的完整文件快照，删除残留文件 | 父版本和已完成评估 |
| 审查、出题 | 对只读调用局部重试 | 已固定数据和候选包 |
| 并行队列 | 单题失败不取消兄弟任务，空闲槽位继续取题 | 成功任务的持久化回执 |
| 取消 | 立即取消调用及退避等待 | 已持久化结果；恢复时校验配置 |

普通调用最多重试 3 次，明确的模型传输故障采用独立有界预算。权限、配置绑定、包完整性和未知副作用等错误不通过盲目重试掩盖。耗尽预算后显示真实错误，不以 0 分替代，不伪造完成；其他已排队任务继续完成并保存。

## 人工独立测试的阶段回执

保存在每次实验的 `human-test/evaluations/.phase-checkpoints/`（实际根目录以运行工作区为准）。每个文件对应独立的轮次、题目、试次和候选包，包含已完成执行和可选权威分数。文件为框架私有机器检查点，不交给调优角色，不影响 Agent 可读的简洁会话记录。

对话完成、评分完成分别原子写入回执。恢复首先核对完整实验配置绑定、包、题目和回执摘要：评分失败只重新评分，诊断失败只重新诊断。不同轮次、重复试次、配置或候选包不能复用。损坏记录拒绝恢复，不重采样掩盖错误。

## 运行中实验的兼容升级

默认仍拒绝跨引擎恢复。只有所有者显式请求 `upgrade_call_isolation=true` 才允许旧检查点重试策略升级为单调用隔离；旧、新指纹如实审计。除新策略之外，完整启动请求、数据集（包括人工测试）、模型绑定、评分器、资源、包、并发、重复次数及停止条件必须保持一致。已有成绩和已完成记录继续使用。

## 验证边界

故障注入测试验证调用范围、兄弟任务、文件回滚、分数保留、取消和跨进程阶段恢复。通过测试不能证明模型在真实数据集上达到 0.95；该目标仍需完整、独立测试结果证明。

## 进度持久化与历史列表

独立测试的完整执行记录单独保存在 SQLite 的 `run_test_observations` 表中，进度状态和测试记录在同一事务内提交。普通进度事件只更新状态，不反复序列化、写入未变化的完整测试记录。历史列表只返回摘要，打开具体实验时仍返回完整记录；不减少执行证据。

旧记录在下一次写入时迁移。读取使用一致事务快照，检查记录所属用户和智能体；缺失测试记录会明确报错，不按空测试集处理。测试覆盖写入失败回滚、旧记录迁移、重启恢复和完整详情读取。

19 MB 合成执行记录的局部测量显示，进度持久化从约 342 ms 降至 0.6 ms。这只代表数据库写入开销，不代表模型推理或整轮实验加速同等倍数。升级已有运行环境时，应先让独立测试结束，再重启后台加载改动。

# Sage 2.0.0

Sage 2.0 brings SAgents v2, the Flutter Desktop v2 client, Server v2 with Agent Studio, and the terminal client together under version 2.0.0. Python 3.12 or newer is required.

## Packages

- `sage-2.0.0-py3-none-any.whl`: Python runtime, CLI, Desktop backend, Server backend, AnyTool integration and built-in skills. Install with `python -m pip install ./sage-2.0.0-py3-none-any.whl`; Server installations also need the `server-v2` extra.
- `sage-2.0.0.tar.gz`: Python source distribution.
- `Sage-2.0.0-source.tar.gz`: tracked repository source, including the Flutter client and deployment references.
- `Sage-2.0.0-server-web.tar.gz`: built Server v2 Web assets. Serve these assets together with the Server v2 API according to its guide.
- `SHA256SUMS`: checksums for downloadable packages.

Desktop installers are built entirely by GitHub Actions from `app/v2/desktop`:

- macOS arm64 / x86_64: DMG, drag Sage into Applications.
- Windows x86_64: per-user setup executable.
- Linux arm64 / x86_64: DEB and portable tar.gz. GTK and bubblewrap remain system dependencies.

Each desktop package contains relocatable CPython, the v2 backend and built-in skills; no repository checkout or system Python is required. Before packaging, Actions moves the application to a new path and verifies backend startup, authenticated health and graceful shutdown from outside the repository. macOS uses ad-hoc signing and is not notarized; Windows installers are not code-signed. The old Tauri installers and updater feed remain v1.

All packages must pass verification before Actions creates the `v2.0.0` tag and publishes this release.

## Version boundaries / 版本边界

| Area / 内容 | 2.0 status / 状态 |
| --- | --- |
| SAgents v2, Desktop v2, Server v2 | Current 2.0 implementations / 当前实现 |
| README and current documentation / 主要文档 | V2 entry points / 指向 v2 |
| Python, Flutter, Server API/Web, Terminal package versions | 2.0.0 |
| `sage v2 …`, `from sagents.v2 import …` | Explicit v2 entry points / 显式 v2 入口 |
| Other legacy `sage` commands, `from sagents import SAgent` | V1 compatibility / 保留 v1 兼容语义 |
| `app/v1`, `sagents/v1`, historical notes, `docs/archive` | Retained legacy source / 保留历史内容 |
| Compose/Kubernetes, existing deployment images | V1 deployment references / 仍部署 v1 |
| Legacy Desktop release workflow | Archived; no v1 application builds / 已归档，不再打包旧应用 |

Server v2 supports one worker. Built-in runtime stores do not establish distributed deployment support. This version number does not change those execution boundaries.

2.0 发布统一了当前产品版本和发布包；仓库仍保留 v1 代码、兼容入口与旧部署文件，因此不能把整个仓库都视为已迁移到 v2。桌面端安装与源码启动见 `app/v2/desktop/README.md`，服务端启动见 `app/v2/server/README.md`。

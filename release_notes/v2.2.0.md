# Sage 2.2.0

## 新增与改进

- **桌面插件**。在桌面端上传、打开和固定 HTML/CSS/JavaScript 插件。Agent 可以用内置插件开发 Skill 与示例生成、注册插件，并在发起请求的窗口打开。插件可通过宿主接口使用存储及获授权的能力。
- **桌面工作台**。改进项目导航、对话历史恢复、消息和工具过程展示。开启「优先交互 UI」后按对话预加载 OpenUI；关闭后省去这部分上下文。
- **待机资源**。Agent 状态刷新只读取活跃评估的摘要，空闲时降低 Agent 列表和 Studio 刷新频率，挂起的会话树每 5 秒检查一次。OpenUI 解析进程空闲 30 秒后回收。
- **Sage Voice**。仓库新增独立语音客户端，支持流式语音、实时字幕和打断。可以逐项启用 Agent 工具，编辑中英文进度播报，使用临时工作区和目标模式。Voice 从源码单独运行。
- **Skill 与执行恢复**。支持按 Run 授权发现和按引用加载 Skill，并支持 Skill 版本管理。改进模型能力探测、工具或模型调用失败后的受限恢复，以及本地沙箱的联网与 Office 文档转换。
- **内置 Skill 调整**。缩减随安装包分发的通用 Skill，新增桌面插件开发 Skill 与示例。
- **RSI、Server 与诊断**。完善数据集治理、重复评估与版本追踪，新增成对网页设计评估。增加 Feishu 等 IM 集成能力、运行耗时和请求诊断，并扩展 SQL 观测存储与 libSQL 记忆后端。

## Highlights

- **Desktop plugins** support installation, pinning and opening from the workspace. Agents can build and register HTML/CSS/JavaScript plugins with the built-in development Skill and examples.
- **Desktop workspace** improves project navigation, conversation recovery and activity rendering. Interactive UI is enabled per conversation.
- **Idle resources** improve through lightweight Agent status checks, slower idle Studio and suspended session-tree polling, and automatic shutdown of the idle OpenUI parser process.
- **Sage Voice** adds a separate source-run client with streaming speech, interruption, subtitles, configurable tools and progress announcements.
- **Skills and runtime** add Run-scoped discovery, reference loading, Skill version management and bounded recovery for model and tool failures. Sandbox networking and Office conversion are improved.
- **Bundled Skills** ship a smaller general-purpose collection and add the Desktop plugin development Skill and examples.
- **RSI, Server and diagnostics** expand dataset and evaluation workflows, IM integrations, request timings, SQL observability and libSQL memory support.

## 安装包 / Packages

- macOS arm64 / x86_64 · DMG
- Windows x86_64 · per-user setup executable
- Linux arm64 / x86_64 · DEB and portable tar.gz
- Python · wheel and source distribution
- Repository source and Server Web assets
- `SHA256SUMS` · package checksums

桌面包内置 Python、Node.js 和 OpenUI 解析器。Windows 插件需要 WebView2，Linux 插件需要 WebKitGTK 4.1。macOS 安装包未公证，Windows 安装包未签名。独立 Python 安装要求 3.12 或以上，Server v2 仍要求单 worker 部署。

Desktop bundles include Python, Node.js and the OpenUI parser. Plugins require WebView2 on Windows or WebKitGTK 4.1 on Linux. macOS installers are not notarized and Windows installers are unsigned. Standalone Python requires 3.12 or later. Server v2 uses a single worker.

# Sage 2.1.0

## Native interactive UI / 原生交互式界面

Sage Desktop now uses the official [OpenUI](https://github.com/thesysdev/openui) parser with its own native Flutter Glass renderer. Assistant output renders incrementally as text arrives, with light and dark themes and 31 registered component types. This is a supported native component subset, not the upstream Web renderer or OpenUI Cloud Reports API.

Desktop 使用 OpenUI 官方解析器和 Flutter 原生 Glass 组件随文本输出增量渲染，支持深浅色与 31 类注册组件。加号菜单可开启“优先交互 UI”，设置 → 通用可指定新聊天的默认值；开启时自动加载内置 Skill，无需调用工具加载渲染能力。

- Local computations bind inputs, metrics, charts and progress without a model round trip. Submission buttons explicitly hand values back to the assistant.
- Calculators update locally; chart hover coordinates, input contrast and compact layouts have been improved.
- Parser validation errors reach the next model request for bounded repair. Replaced drafts appear as one-line entries in the Process Panel and can be inspected in the sidebar.
- Presentations stream into native 16:9 slides, with sidebar thumbnails, navigation, fullscreen presentation and editable PPTX export after validation.
- 本地计算随输入即时更新；提交按钮仅用于把参数交回助手。旧稿收进过程面板，可在侧栏查看；幻灯片支持流式预览和可编辑 PPTX 导出。旧的文件制作 PPT Skill 已移除。

Generated output still depends on the model. Invalid final output remains a read-only preview; this release does not guarantee that every model response passes validation. PPTX import, freeform slide editing and animation are not supported.

模型输出仍可能未通过校验，此时保留只读预览，不开放提交或导出。不支持旧 PPTX 导入、自由拖拽编辑和动画。

## Other changes / 其他更新

Includes the changes merged since 2.0.0: the OrcaRouter provider preset, Server v2 internal-network chat integration, administrator data management, Linux execution identity configuration, and Server Web interaction improvements. See repository documentation for deployment-specific behavior.

同时包含 2.0.0 之后合入的 OrcaRouter 模型预设、Server v2 内网聊天接入、管理员数据管理、Linux 执行身份配置及 Web 交互改进。

## Packages / 安装包

- `sage-2.1.0-py3-none-any.whl` and `sage-2.1.0.tar.gz`: Python runtime and source distribution; Python 3.12+ is required. Server installations also need the `server-v2` extra.
- `Sage-2.1.0-source.tar.gz` and `Sage-2.1.0-server-web.tar.gz`: repository source and built Server Web assets.
- macOS arm64 / x86_64: DMG installers.
- Windows x86_64: per-user setup executable.
- Linux arm64 / x86_64: DEB and portable tar.gz packages; GTK and bubblewrap remain system dependencies.
- `SHA256SUMS`: package checksums.

Desktop packages include relocatable Python, the v2 backend, built-in skills, Node.js and the bundled official OpenUI parser with third-party license notices. All five desktop targets must pass build and relocation smoke checks before publication. macOS packages use ad-hoc signing and are not notarized; Windows installers are not code-signed.

桌面包内置 Python、v2 后端、Skill、Node.js 和官方 OpenUI 解析器，无需用户另行安装这些运行环境。五个平台构建及迁移路径冒烟检查全部通过后才发布。macOS 未公证，Windows 未做代码签名。

## Compatibility / 兼容边界

Product package versions are 2.1.0; the architecture and explicit entry points remain v2 (`sage v2 …`, `sagents.v2`, `app/v2`). Legacy v1 sources and compatibility commands remain available. Desktop does not import v1 data. Server v2 supports a single worker; this release does not establish distributed store support.

产品版本升级至 2.1.0，架构目录和显式入口仍为 v2。保留 v1 源码及兼容入口；Desktop 不导入 v1 数据，Server v2 仍按单 worker 部署。

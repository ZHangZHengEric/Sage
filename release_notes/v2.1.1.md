# Sage 2.1.1

Patch release containing the changes merged since 2.1.0.

本次补丁版本包含 2.1.0 之后合入的更新。

## Changes / 更新

- Improve Desktop agent configuration, resource selection, skill import, settings and chat history rendering.
- Unify v2 agent and Team execution, improve durable recovery, and suspend uncertain tool outcomes for reconciliation.
- Improve sandbox execution, shared Team sandbox leases, workspace isolation and session authorization.
- Improve Server model and plugin configuration, session diagnostics, and request latency reporting.
- Save oversized tool results to workspace files with bounded inline previews, and avoid redundant or ineffective advisory context compression.
- 改进桌面端 Agent 配置、资源选择、Skill 导入、设置及聊天历史展示。
- 统一 v2 Agent 与 Team 执行流程，改进持久化恢复，并在工具执行结果不确定时暂停等待核对。
- 改进沙箱执行、Team 沙箱共享、工作空间隔离与会话授权。
- 改进 Server 模型与插件配置、会话诊断和请求耗时统计。
- 大型工具结果保存到工作区文件并保留受限预览，避免重复或无效的建议性上下文压缩。

## Packages / 安装包

- macOS arm64 / x86_64: DMG installers.
- Windows x86_64: per-user setup executable.
- Linux arm64 / x86_64: DEB and portable tar.gz packages.
- `sage-2.1.1-py3-none-any.whl` and `sage-2.1.1.tar.gz`: Python distributions.
- `Sage-2.1.1-source.tar.gz` and `Sage-2.1.1-server-web.tar.gz`: repository source and built Server Web assets.
- `SHA256SUMS`: package checksums.

Desktop packages include Python, the v2 backend, built-in skills, Node.js and the official OpenUI parser. All five desktop targets must pass build and relocation smoke checks before publication. macOS packages use ad-hoc signing and are not notarized; Windows installers are not code-signed. Linux requires GTK and bubblewrap. Standalone Python installations require Python 3.12+; Server installations also need the `server-v2` extra.

桌面包内置 Python、v2 后端、Skill、Node.js 与官方 OpenUI 解析器。五个平台全部通过构建与迁移路径冒烟检查后发布。macOS 未公证，Windows 未做代码签名。Linux 需要 GTK 与 bubblewrap；单独安装 Python 包需要 Python 3.12+，Server 还需安装 `server-v2` 扩展依赖。

## Compatibility / 兼容边界

Product version is 2.1.1; architecture and explicit entry points remain v2. Desktop does not import v1 data. Server v2 requires a single worker; this release does not establish distributed store support.

产品版本为 2.1.1，架构与显式入口仍为 v2。Desktop 不导入 v1 数据，Server v2 仍要求单 worker 部署。

# 外部平台集成

`integrations/` 存放安装、运行在外部平台中，用于接入 Sage 的插件和连接器。目录按**运行宿主与独立交付边界**组织：每个子目录是一份可单独安装的集成组件，有自己的依赖、配置、版本和使用说明。

例如，AstrBot 桥接插件安装在 AstrBot 服务端，通过 A2A 调用 Sage Server；它的代码归属外部平台集成，Agent 执行、租户授权和任务状态仍由 Sage Server 管理。

## 职责与边界

这里的组件负责外部平台的消息或事件转换、Sage 接口调用，以及结果返回。Sage 保留其租户、Agent、会话和任务的权威数据；集成组件可以保存必要的连接配置、会话映射和投递回执。

| 内容 | 所属目录 |
| --- | --- |
| 安装到外部平台、可独立交付的 Sage 插件或连接器 | `integrations/` |
| Sage Server 内部运行的业务模块和 IM 渠道适配 | `app/v2/server/`、`app/v2/server/im/` |
| Agent 运行时及其扩展实现 | `sagents/v2/` |
| 独立运行的 MCP 服务 | `mcp_servers/` |
| API 调用示例和接入演示 | `examples/` |
| 部署编排、镜像和环境配置模板 | `deploy/` |

完整仓库分层见[源码布局说明](../docs/VERSIONED_LAYOUT.md)。

## 当前提供

| 组件 | 安装宿主 | Sage 接口 | 当前能力 |
| --- | --- | --- | --- |
| [AstrBot Sage Bridge](astrbot_plugin_sage/README.md) | AstrBot 服务端 | Server v2 的 A2A 1.0 接口 | 多机器人分别绑定用户/Agent 凭据、发送人及会话白名单、文本与图片输入、文本回复、持久会话、消息去重、任务查询和取消 |

AstrBot 插件提供 `/sage` 帮助、`/sage status` 查询、`/sage cancel` 取消和 `/sage new` 新会话。首版长任务结果通过查询获取，审批和补充输入在 Sage Web 完成；尚不提供后台主动推送、语音、视频或通用文件收发。安装要求、配置方法和恢复边界以[插件说明](astrbot_plugin_sage/README.md)为准。

当前仅提供上述 AstrBot 插件。后续接入其他外部平台时，按相同职责新增独立组件，不预建尚未实现的目录。

## 新增组件约定

- **独立安装**：子目录包含入口、宿主要求、依赖声明、配置示例和 README；名称遵循目标平台的插件命名规范。
- **公开接口**：通过目标 Sage 版本已公开的接口通信，避免导入 Sage Server 或 Agent 运行时的内部业务实现。
- **明确兼容性**：组件独立版本化，在自身说明中声明支持的宿主、Sage 和协议版本；不因目录未带 `v2` 就默认兼容所有 Sage 版本。
- **清楚的授权来源**：凭据与租户、Agent 绑定由可信配置确定，外部消息不能自行指定或扩大 Sage 权限。
- **代码与数据分离**：凭据、会话映射和运行数据按宿主规范存储，源码只包含无真实密钥的示例。
- **可验证**：测试放在 `tests/integrations/`，覆盖协议转换、授权隔离和异常恢复；各组件 README 记录验证命令与尚未验证的外部平台行为。

The audio, speech, turn detection, and session code in this directory is adapted
from Lalk, revision `48a84bd8f295203fb6f7182cf3ae7ea58ed3de66`, under the Apache
License 2.0. The upstream license and the bundled model licenses are included.

Sage Voice adapts the session and streaming turn to a text-only Agent interface
and leaves conversation state with SAgents v2. The standalone Lalk server,
desktop UI, Bumblehive integration, local ASR model and RNNoise filter are omitted.

# 智能体能力编排

采用已确认的 A 方案：左侧节点画布，右侧配置检查器。适用于智能体编辑器和 Studio 的运行能力配置，属于中高密度配置工作台。

- 节点展示当前方案、默认继承、自定义和未保存状态。点击后在右侧展示全部选项、参数、行为影响及相对已保存配置的变更。
- 打开智能体默认定位第一个基本信息分区；能力编排与其他分区连续排列，上下滚动进入并同步高亮导航，页签点击用于滚动定位。
- 可选范围、可用性和参数 Schema 取自 Server 插件目录。页面说明是配置推演，实际运行结果通过试运行验证。
- 连线表示能力依赖，不表示固定执行顺序，也不修改工作流连线。工作流定义仍在 Studio 的工作流分区编辑。
- Server 默认与智能体覆盖保持现有合并语义；切换实现重置该实现的参数，恢复默认移除该能力覆盖，保留其他能力和资源。
- 使用现有浅色表面、边框、字体和间距；选中节点及方案采用低饱和绿色。暗色模式使用对应高对比度色值。
- 窄屏上下排列画布与检查器，节点可缩放并滚动。画布节点、选项和参数支持键盘操作，只读状态可查看并禁止修改。
- 动效仅用于节点和方案的边框、背景反馈：120ms ease-out，无位置动画；尊重 reduced-motion。
- 不添加页面副标题，不增加业务存储，不引入动画或图形库。
- 智能体画布按每行三个紧凑节点展示，完整包含 Server 声明的智能体可配置能力及模型路由，不混入系统基础设施插件。模型只在画布“模型配置”节点编辑主模型、辅助模型，移除独立模型配置分区和 tab，保留模型依赖连线。依赖树采用无交叉的正交布线；窄屏将依赖独立分行展示，防止连线被节点遮挡。
- 「系统设置 → 插件」配置系统默认，使用分类列表和右侧表单，不使用画布；移除顶部标题、标签和搜索，字号以上一级侧边菜单的 14px 为上限，正文、选项和标题为 14px，辅助信息为 12px，实现选项使用分隔线列表，不使用卡片嵌套；宽屏不限制内容最大宽度，实现选择与影响说明、参数分为左右两栏，窄屏上下排列。目录保留只有一种实现的能力和部署注入项；仅 Server 明确允许且有可选实现或页面参数的项目可修改；其余分类和实现标记“不可修改”，禁用选择与参数编辑，并隐藏保存入口。区分运行中、已保存和待重启状态；分类间切换保留未保存草稿。

- 系统插件与智能体插件选项在名称后显示灰色插件 code，长 code 自然换行；移除“技术信息”折叠区。

## 模型供应商：自然卡片 A 方案

2026-10-19 已确认。范围为模型列表与配置详情，采用消费级设置页和表单组合，中等信息密度。浏览、筛选模型，打开配置，按组编辑并保存；沿用现有 API、所有者作用域和能力探测结果。

- 列表使用自适应卡片，显示供应商、模型名称、默认标记、已声明能力、地址和真实探测状态。过滤与搜索只改变展示。
- 详情采用宽 760px 的居中弹框，依次展示连接设置、生成偏好、模型能力、折叠的高级配置与能力探测；保存按钮固定在底部。手机使用单列和贴底详情。
- 配置项问号支持悬停、聚焦、点击及 Escape 关闭，解释配置的作用、影响和模型限制。帮助在只读状态仍可使用。密钥默认隐藏；修改配置使原探测结果失效。
- 页面不额外添加副标题。不新增业务存储。其他用户的配置只读；默认模型需先切换才能删除，删除需在详情中确认。
- 色彩：背景 #f7f8f5、卡片 #ffffff、正文 #252b24、辅助文字 #6b7466、边框 #e0e5da、主色 #465c38；暗色用对应高对比度语义色。样式与变量限定在 .model-page 和 .model-dialog，不影响其他页面。
- 字体沿用现有中文黑体，标题 26px、模型名 17px、操作文字 12–13px、状态 11px。卡片圆角 20px，详情 24px，输入框 10px；卡片间距 16px，表单组内间距 18px。
- 图标沿用 AppIcon 自定义 SVG：24px 网格、1.7px 描边、圆端点、currentColor。小图标不使用生成图片，供应商使用字母标记。
- Motion DNA：理解与反馈优先，轻量、克制；卡片悬停抬升 2px，220ms cubic-bezier(.2,.7,.2,1)；开关 150ms。使用 CSS（L1），不增加动画依赖。reduced-motion 关闭位移动效。
- 状态覆盖：加载骨架、首次使用、无搜索结果、加载失败重试、保存失败保留输入、操作成功反馈与只读详情。

- MCP 和远端智能体沿用现有增删改与发现 API；目录、连接详情、编辑表单使用同一视觉层级。密钥不回显，协议、地址与认证提供问号说明，删除增加确认，其他用户的连接只读。

- 说明视图只在渲染 SKILL.md 时隐藏开头 frontmatter，源码不改写；文件切换与关闭使用请求序号，忽略过期响应。查看脚本不执行脚本。
- ZIP 导入逐个展示结果，部分失败保留失败文件供重试；上传中禁止修改队列。删除技能需确认并保持所有者边界，导入不自动修改任何智能体的技能绑定。
- 桌面工具详情 840px、技能详情 1040px；窄屏单列、贴底详情和固定操作栏。CSS 仅作用于 `.resource-page`、`.resource-dialog`，卡片悬停抬升 2px / 220ms；reduced-motion 移除位移动效。图标继续使用 AppIcon，不引入新依赖。
- 验证包含真实目录定义的 API 投影、技能读写边界、文件切换与关闭竞态、导入失败重试，以及示例数据的实际组件浏览器检查。

## 系统设置：清晰分栏 A 方案

2026-10-19 确认。范围为系统菜单下的插件管理、用户管理及执行配置详情。插件属于中等密度配置工作台，用户属于列表与只读详情；以克制的消费级设置体验提高可读性，保留现有配置和权限语义。

- 插件采用分类导航、分隔线实现列表、影响与参数说明三栏；窄屏改为横向分类与纵向表单。字号不超过侧边菜单的 14px，不添加顶部副标题、搜索或标签栏。
- 明确区分运行中、已保存默认、待重启与未保存草稿；可查看待生效项目。切换分类保留草稿，底部固定保存入口展示前后变化，保存失败保留输入；冲突重载只丢弃当前分类的草稿。
- 仅 Server 声明可配置且存在选择或参数的项目允许编辑。固定实现、宿主注入项保留目录并只读，不出现保存操作。保存仍使用现有 revision 接口，生效仍依赖 Server 重启。
- 用户列表使用角色筛选、用户名或 ID 搜索、ID 复制与执行权限摘要；执行配置居中只读弹框展示原始用户策略。窄屏隐藏 ID 和权限摘要列，详情保留全部信息并贴底显示。
- 配置项问号使用现有 FieldHelp，悬停、聚焦、点击可查看影响，Escape 关闭；Schema 提供更多参数时沿用 Schema 描述，不虚构行为。只读状态同样可查看帮助。
- 语义色限定在 `.system-settings`：背景 #f8f9f6、卡片 #ffffff、正文 #283126、辅助 #6d7766、边框 #e1e6dc、主色 #44663b、待生效 #91621b。暗色提供对应语义色。间距以 4px 为基础，表面圆角 13–14px，详情圆角 20px。
- 图标沿用 AppIcon；Vue 页面仅使用 CSS L1 的单选反馈 140ms ease-out，reduced-motion 关闭动画，不增加依赖、业务存储或后台写接口。
- 覆盖加载、空列表、无筛选结果、失败重试、保存冲突保留草稿、只读和窄屏状态。

- 逐工具审批弹框沿用资源选择器精简样式：每行仅工具名称与继承默认/需要询问/免审批三态选择，不增加批量审批按钮或右侧重复清单。打开弹框时才按所有者作用域请求真实审批目录；直接使用 approval_key，未知旧规则保留可移除，不从工具名猜审批键。取消、关闭、Escape 丢弃独立草稿；确认只更新当前页面，顶部保存持久化。切回继承删除对应覆盖；不修改工具授权、默认审批、命令权限或沙箱。只读可查阅，加载和失败时禁止确认并可重试。


## 会话历史与新会话：简洁对话 A 方案

2026-10-19 确认并按当轮反馈收敛。历史属于消费级记录列表，中等密度；新会话属于低密度对话入口。复用「瓷白石墨」颜色、圆角和基础控件，不增加页面副标题。

- 历史按更新时间倒序平铺，宽屏铺满主内容区，仅保留全站统一页边距，不限制 1060px 宽度、不分日期组、不设详情预览栏。顶部仅保留标题或智能体搜索与智能体筛选，移除会话所有者筛选及用户名搜索匹配；列表只显示既有标题、智能体、更新时间和外部所有者只读标记。
- 行尾始终显示无文字、无边框的三个实心圆点下拉图标；图标加大并使用正文色，保留可访问名称，悬停和展开时仅以轻底色反馈。菜单提供继续对话或只读查看、管理员下载诊断包和本人会话删除；支持键盘、Escape、外部点击关闭及焦点返回。删除使用公共确认弹框，失败保留当前项供重试。
- 新会话仅保留问候、居中输入框、智能体选择和工作空间入口。输入框内智能体选择器按当前名称收紧宽度，不受候选项最长名称影响；常态无边框，悬停轻底色、键盘聚焦保留焦点环，长名称限制最大宽度。用户明确移除快捷提问与最近会话；不添加替代推荐区。发送后转为现有消息流和底部输入框。刷新初始化采用静默加载：不显示“正在准备会话”，未就绪时仅用普通输入提示并隐藏智能体选择器，名称就绪后再显示，不将缓存的智能体 ID 用作名称；配置读取失败和缺少配置仍保留明确提示，加载期间禁止发送并保留草稿。
- 普通会话在选定智能体后发送；已绑定会话、Package 与运行中的智能体不可切换。缺少可用配置或读取失败禁用发送，重载保留输入；中文输入法确认不会误发送。Package 运行继续沿用既有内嵌配置与 AG-UI 通道。
- 消息回放、滚动加载、审批恢复、只读会话和工作空间沿用既有 API 与作用域；不扩展业务或审计存储。桌面、390px 窄屏和暗色模式共用同一组件，低强度 CSS 反馈使用公共动效变量。
- 探索预览位于本轮 conversation-design；落地验收使用实际 Vue 页面配合本地示例 API，不写真实会话数据。


## 对话过程：轻量对话流 A

2026-10-19 用户确认。消费级对话界面结合中等密度执行记录；保持消息时间顺序、底部输入、工作空间、连续滚动与全站瓷白石墨主题。原始消息、工具执行、审批决定仍由现有 AG-UI 与 Server 接口提供，不扩展业务或审计存储。

- 正文 14px / 1.85，窄屏 13px / 1.8；用户消息轻气泡，助手正文开放阅读。代码带语言与复制入口，表格局部滚动，引用与列表层级清晰；只渲染 Markdown，模型提供的 HTML 作为文本显示，链接与图片限制安全 URL 协议。
- 工具记录就地展开，参数、原始输出分为两个可键盘切换的页签并支持复制。状态采用文字和图标双表达，保留准备、待执行、执行中、待审批、完成、拒绝、失败、未执行、未知、核对、取消与未完成的区别；失败默认展开错误输出，不添加工具强制重跑按钮。
- 仅合并相邻、空正文的助手工具父消息用于展示，不改写 SDK 消息或回放事件。未知来源保留原始工具名，不按名称冒充内置工具。结果中的文件路径可通过既有工作空间入口查阅；只有已完成且返回成功的结果才提供该入口。
- 审批以服务端允许的决定为边界。精确匹配待审批调用的名称与参数（若有明确调用 ID 则优先），关联不唯一时在消息末尾保留独立审批，不猜测某个调用。一个未决请求只显示一处决定按钮；等待时隐藏输入框及重复状态提示，底部仅保留紧凑的“查看审批”定位入口，处理后恢复输入框与已有草稿。
- 审批显示原始调用、文件路径、实际 mode、副作用级别、风险与完整参数；允许一次为主操作，拒绝为次操作，允许并记住及取消运行进入带文字标识的更多操作。记忆问号说明实际 payload 的作用域及匹配范围；不宣称永久或全局放行。
- 提交中保留原请求并禁用重复决定，恢复流仍从原基线重放。失败保留请求与回答供重试；成功后仅列表刷新失败不能重新恢复已处理请求。切换会话忽略过期决定结果。补充信息只有文本决定要求非空，拒绝与取消不附带无关回答；只读可查阅、禁止决定和发送。
- 运行中输入框持续可编辑：空输入时为终止按钮，有内容时切换为发送。发送通过 Web 登录态接口向原 Run 的 V2 steering inbox 追加输入，在下一处理节点接收，不创建并行 Run。未接收的补充显示“待接收”，正式接收后由原消息流替换；任务结束前未接收则恢复到草稿，网络失败保留内容与重试标识。
- 终止通过当前用户、会话和精确 Run 校验后调用现有 V2 CancelRun；等待取消事件到达再恢复待发送状态，保留已经输出的内容。审批提交后恢复执行时重新显示输入框；切换会话隔离旧运行回调。新增接口不扩展业务或审计存储。
- 样式集中在 conversation-process.css，颜色、圆角与反馈时间引用现有 theme.css，图标沿用 AppIcon；移除旧工具与审批样式。CSS 只提供 150ms 反馈和真实执行中 spinner，尊重 reduced-motion，不增加依赖或页面副标题。
